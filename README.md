# PPF Athletics — Performance OS

**Built for Performance. Proven by Results.**

> PPF is not where athletes come to "work out." It is where serious athletes come to build a cleaner, stronger, faster, more evaluatable version of themselves under a standard that is coached, measured, and proven.

## The Concept

PPF Performance OS — the first performance website that feels like a live draft-prep command center. Every scroll reveals proof, every section feels coached, and every detail makes it obvious that this place was built for athletes chasing verified results, not just workouts.

**TIMED. MEASURED. COACHED. VERIFIED.**

## Website Architecture

The site is built in **narrative phases**, not generic sections:

| Phase | Section | Purpose |
|-------|---------|---------|
| 1 | Entry Sequence | System boot-up animation establishing authority |
| 1 | Hero Command Center | 2027 Combine & Pro Day Prep dashboard |
| 2 | The Standard | "Coached, not assumed" pillar system |
| 2 | Profile Build | Interactive performance anatomy with clickable zones |
| 3 | Proof Dashboard | Animated verified metrics with context |
| 3 | Draft Board | Filterable athlete profiles as dossiers |
| 3 | Movement Carryover | PPF's proprietary training-to-outcome analysis |
| 4 | The System | 5-phase training methodology timeline |
| 4 | Leadership | Richard & Rebecca as system architects |
| 4 | Outcome Wall | Cinematic proof environment |
| 5 | What the Room Sees | Multi-audience decision-maker intelligence |
| 5 | Enter the System | Premium application/intake experience |

## Signature Features

- **Standard Meter** — Football field measurement rail that tracks scroll progress
- **Performance Anatomy** — Interactive body silhouette with clickable training zones
- **Draft Board** — Filterable athlete profiles with full dossier expansion
- **Movement Carryover Analysis** — Proprietary PPF methodology visualization
- **Outcome Wall** — Masonry grid of verified metrics, quotes, and placements

## Tech Stack

- **Next.js 16** with App Router
- **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion** for premium animations
- Static export ready

## Getting Started

```bash
npm install
npm run dev     # Development server at localhost:3000
npm run build   # Production build
npm run start   # Production server
```
